# Google Business Profile checklist (H4 to H13)

There is no free API for this, so it is a checklist Andru works through in the profile (or with the client on a call). Fill it with this client's values before handing it over, so each line says what it should be, not only what to check. Put the filled version in the report under "Needs Andru".

| ID | Check | What it should be | Sev |
|---|---|---|---|
| H4 | Business name | The real-world name exactly as on the sign, truck and invoices. No keywords or towns added ("Smith Homes", not "Smith Homes Custom Home Builder Lake Lanier"). Keyword stuffing in the name is the most common reason profiles get suspended | B |
| H5 | Categories | Primary: **Custom home builder**. Secondary, only those that are true: Home builder, General contractor, Construction company, Remodeler (only if they remodel) | H |
| H6 | Service areas | Each blueprint service area (up to 20), as towns or counties, matching the site's area pages and `areaServed`. Address hidden if clients never visit the office | H |
| H7 | Hours | Real office hours, same as the site and schema; holiday hours set | H |
| H8 | Website link | `https://<domain>/?utm_source=google&utm_medium=organic&utm_campaign=gbp` so GBP visits show separately in GA4. The landing URL must not redirect | H |
| H9 | Photos | 15 or more real, recent project photos (exteriors, interiors, the team on site), logo and cover set. No stock photos. New photos with every finished home | H |
| H10 | Reviews | A review link (from the profile's "Ask for reviews") on the site's contact or thank-you page and in the client's closeout email. Every review answered. Never offer anything for reviews (against Google's policy) | H |
| H11 | Services | Custom home building, lot evaluation, design-build, and anything else true, with short plain descriptions | H |
| H12 | Description | 750 characters max, plain, who they build for and where, no URLs or promotions, no em dashes | H |
| H13 | Ownership and access | Verified; the client is the primary owner; Andru is a manager, not the owner; the phone matches the site | B |

On launch day, also: update the website link to the new domain (H8), and post an update with a finished home and a link to its new page.

At the 2-week check: Performance tab views, searches and website clicks for the last 14 days compared with the 14 before launch (if Andru can see them), and whether the UTM visits show in GA4 (K7).
